# mintlify

Mintlify Landing Page Clone

A static clone of the Netlify landing page built to practice modern UI layout and responsive design.

Tech Stack

HTML5 

index

CSS3 (Flexbox, Grid, variables) 

style

What’s Included

Sticky blurred navbar

Hero section with CTA

Feature and intro sections

Responsive layout

Footer with newsletter UI

Dark theme styling

How to Run

Clone the repo

Open index.html in a browser
(or use Live Server)

Purpose

Built for learning and UI practice.
No frameworks, no JS, pure HTML + CSS.

Status

UI complete.
Images and minor polish can be improved.
